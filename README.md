# Luis Trejos — personal profile

Personal site for [Luis Trejos](https://github.com/luis-trejos-tabares-gh): experience, skills, and selected work.

```bash
pnpm install
pnpm dev
```

Edit content in `src/data/profile.ts`. To show a résumé download, drop a PDF at `public/resume.pdf` and set `contact.cvUrl` to `/resume.pdf`.
